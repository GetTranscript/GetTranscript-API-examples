# GetTranscript API — Code Examples 🚀

This repository contains practical code examples for integrating the **[GetTranscript API](https://gettranscript.app/documentation)** into your applications.

Our API allows you to programmatically extract YouTube transcripts, subtitles, and captions for single videos, playlists, and entire channels. 

## 🛠 Features
*   Extract transcripts in **TXT, MD, SRT, VTT, JSON, or CSV**.
*   Process single videos or bulk channels.
*   Word-level timestamps.

## 📦 Prerequisites
To use these examples, you will need an API key. 
You can get one for free in your **[GetTranscript Dashboard](https://gettranscript.app/api-keys)**.
